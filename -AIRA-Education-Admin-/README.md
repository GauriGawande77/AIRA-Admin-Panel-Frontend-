# AIRA Education Platform

Welcome to the AIRA Education Platform root repository! This project is a modern, modular e-learning and e-commerce administrative platform. 

It currently consists of a dynamic React (Vite) frontend dashboard.

---

## 📁 Project Structure

### `AIRA-Admin/frontend/` (Frontend UI)
*   **Description:** A sleek, modern administrative dashboard built with React.
*   **Tech Stack:** React, Vite, Tailwind CSS (or standard CSS), Lucide React (icons).

---

## 🚀 How to Use and Run this

To run the application locally, you need to start the React frontend.

### Prerequisites
*   **Node.js 18+** installed (with `npm`)

### Step 1: Start the Frontend (React UI)

**Important for Windows Users:** Use **Command Prompt** (`cmd`) to start the frontend, as PowerShell's default execution policies often block `npm` scripts.

1. Open a Command Prompt window.
2. Navigate to the frontend directory:
   ```cmd
   cd "AIRA-Admin\frontend"
   ```
3. Install dependencies (only required the first time):
   ```cmd
   npm install
   ```
4. Start the development server:
   ```cmd
   npm run dev
   ```
   *The frontend server will start on `http://localhost:5173`.*
